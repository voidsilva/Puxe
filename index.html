Config
Os downloads passam por um servidor com o cobalt, que é código aberto. O servidor padrão já vem configurado, ninguém precisa instalar nada. Aqui você pode trocar por outro ou usar o seu.

Opcional: servidor no seu computador

      
Útil se o servidor padrão estiver lento ou se o YouTube bloquear o servidor na nuvem. Sua internet de casa costuma ser bloqueada bem menos.

      
    
        
  1. Instale o Docker Desktop (Windows, Mac ou Linux).
    2. 
        
  2. Rode no terminal:
    docker run -d --name cobalt --restart unless-stopped -p 9000:9000 -e API_URL=http://localhost:9000/ ghcr.io/imputnet/cobalt:latest
    3. 
        
  3. Coloque http://localhost:9000 no topo da lista ao lado e clique em Testar.
    4. 
      

      
Se o navegador perguntar sobre acesso à rede local, permita. Quando um download falha, aparecem atalhos para o cobalt.tools e para a aba yt-dlp.
